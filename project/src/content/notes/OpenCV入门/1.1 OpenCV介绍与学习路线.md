# 1.1 OpenCV介绍与学习路线

OpenCV 的全名是 **Open Source Computer Vision Library**。它不是“会自动看懂世界的 AI”，更像是一只装满视觉工具的工具箱：从基础的读图、颜色转换、去噪、找边缘、提轮廓、绘图到进阶一些的3d世界的位姿解算、复杂图形的关键点检测……这些工作它都能干。通过合理搭配，这么一套数学工具也能让计算机”看“懂世界。
不过对于一些很复杂图形，如果算力足够，还是建议用一些神经网络，比如使用YOLO。

因此本篇笔记主要介绍**基础**用法，不过多涉及底层数学原理--> 目标是==入门和会用==
非常适合**入门学习**！！！

本篇笔记是以python为接口

```python
import cv2
```

包名叫 `opencv-python`，导入时却写 `cv2`。这个名字是历史遗留，记住就好，不用和它较劲

在开始学习之前，最好需要知道python语法基础，数组的概念，numpy基础用法。

## 一、通过一个例子快速认识OpenCv流程

先看一个具体任务：从摄像头里找到一个红色圆球并得到它在图中的位置坐标。

```text
摄像头读取画面
   ↓
转换到适合分颜色的 HSV
   ↓
按颜色范围生成黑白蒙版（比如在颜色范围内的就是白色）
   ↓
去掉小噪点、补上小缺口
   ↓
找到白色区域的轮廓
   ↓
根据面积、圆度筛选目标
   ↓
得到圆球中心坐标
```

OpenCV 主要负责中间这些“把**像素**一步步变成有用信息”的工作。
之后你就可以用提取出来的信息处理业务逻辑（就是任务代码）了。

> [!important] 一开始不要追求“一个函数直接识别目标”
> 传统视觉通常是一条流水线，一步接一步。

## 二、先把图像看成数组

在 Python 里，OpenCV 图像通常就是 NumPy 数组：

```python
image.shape
# (高度, 宽度, 通道数)
```

例如 `(480, 640, 3)` 表示：

- 480 行像素，也就是高度；
- 640 列像素，也就是宽度；
- 每个像素有 3 个颜色通道。

因此“裁剪一块图像”其实就是切数组。详细概念见 [[1.2 图像、像素与坐标]] 和 [[1.5 NumPy与图像数组]]。

## 三、一条最常见的视觉流水线

以后看到一段很长的 OpenCV 代码，可以先按下面几类拆开：

| 阶段   | 要回答的问题           | 常见函数                                            |
| ---- | ---------------- | ----------------------------------------------- |
| 输入   | 图像从哪里来？          | `imread`、`VideoCapture`、`read`                  |
| 预处理  | 怎样让目标更好找？        | `cvtColor`、`GaussianBlur`、`threshold`、`inRange` |
| 结构整理 | 怎样去噪、补洞、连边？      | `erode`、`dilate`、`morphologyEx`                 |
| 特征提取 | 哪些像素组成**边缘**或物体？ | `Canny`、`findContours`、`approxPolyDP`           |
| 筛选   | 这是不是我要的目标？       | `contourArea`、`arcLength`                       |
| 输出   | 怎样展示或交给控制程序？     | `rectangle`、`putText`、中心坐标                      |

真正写项目时不要把它们糊成一团。建议每个阶段都保留一个能观察的中间结果，例如 `mask`、`edges`、`morph`。

## 五、学习时怎样使用这些笔记

建议顺着编号读，但不要只读不跑：

1. 先复制最小示例，确认代码能执行；
2. 显示每个中间图，不要只看最终框；
3. 改一个参数，观察一个变化；
4. 把函数参数换成自己的话解释；
5. 最后再进入 [[4.1 完整的形状检测流程|完整项目]]。
